# Revit 2027 매개변수 도구 (Parameter Tools)

Autodesk Revit 2027 (.NET 10.0) 환경에서 동작하는 전문 매개변수 관리 및 일괄 처리 애드인 제품군입니다.

---

## 🚀 빠른 설치 방법 (다른 PC에서 사용 시)

1. 저장소의 **`Installer/Revit_Parameter_Tools_2027_Setup.zip`** 파일을 다운로드합니다.
2. 압축을 푼 뒤 폴더 안의 **`Install.bat`** 파일을 더블클릭하여 실행합니다.
3. Revit 2027을 실행하면 상단 리본 메뉴에 **`[매개변수 도구]`** 탭이 자동으로 활성화됩니다.

> **제거 방법**: 필요 없을 때는 폴더 안의 `Uninstall.bat`을 더블클릭하면 깨끗하게 제거됩니다.

---

## 🛠️ 포함된 주요 기능

### 1. 매개변수 복제 & 일괄생성 (`ParameterBatchManager`)
- **설정 복제**: 기존 모델에 정의된 매개변수(분야, 데이터 유형, 매개변수 그룹 등)의 설정을 그대로 복사하여 새 이름으로 즉시 생성
- **다중 일괄 생성**: 여러 개의 매개변수 이름과 타입을 목록으로 등록하여 버튼 한 번으로 프로젝트/공유 매개변수 일괄 생성
- **카테고리 다중 바인딩**: 생성 시 원하는 카테고리를 체크박스로 손쉽게 다중 선택 가능

### 2. 매개변수 데이터 값 복사 & 이전 (`ParameterValueCopier`)
- **A $\rightarrow$ B 값 이전**: 원본 매개변수(A)의 데이터 값을 대상 매개변수(B)로 일괄 복사/주입
- **일람표 가상 필드 지원**:
  - 일람표에서 작성된 **계산된 값(`fx Formula`)** 및 **매개변수 결합(`Combined Parameters`)** 값을 실제 모델 요소에 1:1로 직접 복사
  - 다중 헤더 및 마크 식별자를 통한 1:1 정밀 매칭 (행 밀림 방지)
- **스마트 단위/형변환**: 문자, 실수(길이/면적), 정수, 예/아니오(Yes/No) 간 자동 변환
- **소수점 이하 자릿수 제어**: 기본값 0자리(정수 반올림) 지원 및 1~4자리/원본 유지 선택 가능
- **모달리스(Modeless) 창**: 창을 띄워둔 상태에서도 레빗 뷰 전환, 3D 객체 선택, 특성 창 실시간 조회가 가능
